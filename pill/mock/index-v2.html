v2 changes over v1

  • Shrink-to-orb on idle — after 10s without interaction the capsule collapses to the 28px orb; hover restores it. Wispr's shrink-to-dot, translated to Tymos.
  • No task, still labeled — with no focused task the pill falls back to the phase word ("Focus session" / "Break"), so the time is never unexplained.
  • Flattened glass — one fill, one hairline, one inset highlight. The double gradient and ambient glow are gone; glow now means "running".
  • Hover-revealed actions — pause/skip grow out of the right edge on hover (Flow Bar's grow-from-orb), hidden at rest so the pill stays read-only.
  • Urgency — final 10% shifts the ring to ember and quickens the core pulse. Break ignores urgency.
  • Frozen candle pause — ring freezes at its burned position and grays; core dims instead of the whole pill going translucent.
  • Choreography — expand/collapse and state swaps run on a single 320ms ease; reduced-motion kills all loops.
